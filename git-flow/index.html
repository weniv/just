3

다섯 명령어 한 줄 요약

  • 1 clone 깃허브에 있는 레파지토리를 내 컴퓨터로 통째로 복사. 처음 한 번만 합니다.
  • 2 add 수정·생성·삭제한 파일 중 이번 버전에 포함시킬 것을 골라 모읍니다.
  • 3 commit 모은 파일을 묶어 버전 하나를 만듭니다. 짧은 메시지가 함께 들어갑니다.
  • 4 push 내 컴퓨터에 만들어 둔 버전을 깃허브에 올립니다. 이걸 해야 남이 볼 수 있습니다.
  • 5 pull 깃허브에 있는 최신 버전을 내 컴퓨터로 가져옵니다. 작업 시작 전 습관처럼.
